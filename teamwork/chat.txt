一个 agent 的一部分功能代码应该是什么样的结构？怎么接收输入怎么生成输出内容？怎么与 agent 主体传递信息
Agent 子功能模块代码结构设计
核心思路：模块解耦。子功能不直接操作 Agent 全局状态，只接收标准化输入结构体，执行业务逻辑，返回标准化输出；通过消息 / 上下文对象和 Agent 主体通信，不硬编码依赖主体。
下面用 Python 实现一套通用范式，同时讲清楚输入、输出、和主体通信的方式。
1. 整体架构关系
plaintext
Agent主体（AgentCore）
├─ 维护全局状态：对话历史、记忆、工具列表、任务状态
├─ 调度器：选择要调用的子功能模块
└─ 子功能模块（AgentComponent）
   ├─ 输入：统一的消息结构体（来自主体）
   ├─ 执行逻辑：模块专属能力（检索/规划/工具调用/结果解析）
   └─ 输出：统一返回结构体，交给主体
通信原则
子模块不 import 主体类，消除循环依赖
主体传给模块的不是原始字符串，而是结构化上下文对象
子模块返回结构化结果，主体负责更新全局状态
2. 数据模型：统一输入输出（Pydantic，工业界常用）
定义通用消息载体，所有子模块都复用这套结构。
python
from pydantic import BaseModel, Field
from typing import Any, Optional, Dict, List

# 子模块【输入】：主体传给子功能的数据
class ComponentInput(BaseModel):
    """Agent 传给子组件的标准输入"""
    task_query: str  # 用户原始query
    chat_history: List[Dict[str, str]]  # 对话历史
    agent_memory: Dict[str, Any]  # 长期/短期记忆快照（只读！不要直接修改）
    extra_params: Dict[str, Any] = Field(default_factory=dict) # 模块专属参数
    module_name: str # 当前模块标识

# 子模块【输出】：子功能返回给Agent主体的结果
class ComponentOutput(BaseModel):
    """子组件返回给Agent主体的标准输出"""
    success: bool
    content: str  # 自然语言结果
    data: Dict[str, Any] = Field(default_factory=dict) # 结构化数据（工具返回、规划步骤等）
    need_more_info: bool = False # 是否需要继续调用其他模块
    error_msg: Optional[str] = None

统一接口，主体调度的时候不需要关心内部实现，只调用 run()

class TaskPlannerComponent(AgentComponent):
    name = "task_planner"
    description = "任务拆解规划模块，把大任务拆成子步骤"

    def run(self, input: ComponentInput) -> ComponentOutput:
        try:
            # ========== 子模块内部逻辑 ==========
            # 只能读取 input 里的数据，禁止直接修改 agent_memory
            user_query = input.task_query
            history = input.chat_history

            # 模拟LLM调用做任务拆解
            steps = self._llm_plan(user_query, history)

            return ComponentOutput(
                success=True,
                content=f"已完成任务拆解：{steps}",
                data={"sub_tasks": steps},
                need_more_info=True # 规划完，需要主体继续调用执行模块
            )
        except Exception as e:
            return ComponentOutput(
                success=False,
                content="任务规划失败",
                error_msg=str(e)
            )

    def _llm_plan(self, query: str, history: List[Dict]) -> List[str]:
        # 模块内部私有方法，只在组件内部使用
        return ["步骤1：检索资料", "步骤2：整理信息", "步骤3：生成回答"]
4. Agent 主体：如何调用子模块、传递信息
主体负责：组装输入 → 调用组件 → 拿到输出 → 更新自身状态
python
class AgentCore:
    def __init__(self):
        self.chat_history: List[Dict[str, str]] = []
        self.memory: Dict[str, Any] = {}
        # 注册所有子功能模块
        self.components: Dict[str, AgentComponent] = {
            "task_planner": TaskPlannerComponent()
        }

    def run_agent(self, user_input: str):
        # 1. 准备输入，构造传给子模块的结构体
        component_input = ComponentInput(
            task_query=user_input,
            chat_history=self.chat_history,
            agent_memory=self.memory,
            module_name="task_planner"
        )

        # 2. 调度：调用子功能模块
        planner = self.components["task_planner"]
        result: ComponentOutput = planner.run(component_input)

        # 3. 主体接收子模块输出，更新Agent全局状态
        if result.success:
            print("规划结果：", result.content)
            # 把子模块返回的结构化数据存入agent记忆
            self.memory["last_sub_tasks"] = result.data["sub_tasks"]
            # 追加对话历史
            self.chat_history.append({"role":"assistant", "content": result.content})

            # 4. 根据子模块返回标记，决定下一步动作
            if result.need_more_info:
                print("需要继续调度其他组件执行子任务")
        else:
            print("组件报错：", result.error_msg)

# 启动
if __name__ == "__main__":
    agent = AgentCore()
    agent.run_agent("帮我写一份项目方案")
5. 输入、输出、信息传递详细说明
✅ 子模块如何接收输入
输入是封装好的 ComponentInput 对象，不是零散字符串
数据来源：Agent 主体从自身全局状态（对话、记忆）打包生成
限制：子模块只读输入里的 agent_memory，不能直接修改！所有状态变更必须交给主体。
好处：避免多个子模块并发修改状态造成混乱。
✅ 子模块如何生成输出
所有结果统一包装为 ComponentOutput
分成两块：content 自然语言文本 + data 结构化数据（方便后续程序处理）
附带控制标记：need_more_info、success，用来告诉主体下一步怎么做
✅ 子模块 ↔ Agent 主体 信息传递方式（3 种常用方案）
函数调用传递（上面示例，同步单 Agent 首选）
主体直接调用组件run()，传参、返回对象
适合单线程串行 Agent，简单、调试友好
消息队列（多组件 / 异步 Agent）
主体和子模块通过消息队列（redis/mq）收发标准化消息
组件独立进程，解耦最强，适合分布式 Agent
事件总线（多组件广播）
组件发布事件，主体订阅事件；适合事件驱动型 Agent
❌ 禁止做法：子模块直接读写 Agent 实例属性、全局变量。会造成耦合，难以单独测试子模块。

子组件：继承统一基类，只有一个入口 run(input)

import asyncio
from pydantic import BaseModel, Field
from typing import Any, Optional, Dict, List, Callable
import functools

# ======================
# 数据模型（保持不变）
# ======================
class ComponentInput(BaseModel):
    task_query: str
    chat_history: List[Dict[str, str]]
    agent_memory: Dict[str, Any]
    extra_params: Dict[str, Any] = Field(default_factory=dict)
    module_name: str

class ComponentOutput(BaseModel):
    success: bool
    content: str
    data: Dict[str, Any] = Field(default_factory=dict)
    need_more_info: bool = False
    error_msg: Optional[str] = None


# ======================
# NEW: retry 异步重试装饰器
# ======================
def async_retry(max_retries: int = 2, delay: float = 0.5):
    def decorator(func: Callable):
        @functools.wraps(func)
        async def wrapper(*args, **kwargs):
            attempt = 0
            while attempt <= max_retries:
                try:
                    return await func(*args, **kwargs)
                except Exception as e:
                    attempt += 1
                    if attempt > max_retries:
                        raise e
                    print(f"[Retry] attempt {attempt}, error: {str(e)}")
                    await asyncio.sleep(delay)
        return wrapper
    return decorator

    name: str = "base_component"
    description: str = "base async component"
    timeout: float = 10.0  # NEW: timeout 默认值

class ThoughtComponent(AgentComponent):
    name = "thought"
    description = "ReAct 思考模块：判断下一步动作"
    timeout = 8.0

    @async_retry(max_retries=2, delay=0.3) # NEW: retry
    async def run(self, input: ComponentInput) -> ComponentOutput:
        # 模拟LLM思考：判断下一步是调用工具还是直接回答
        await asyncio.sleep(0.2)

# ======================
# NEW: Agent主体，带 ReAct 循环 + 超时调度
# ======================
class ReActAgentCore:
    def __init__(self):
        self.chat_history: List[Dict[str, str]] = []
        self.memory: Dict[str, Any] = {}
        # 注册组件
        self.components: Dict[str, AgentComponent] = {
            "thought": ThoughtComponent(),
            "weather_tool": WeatherToolComponent()
        }

    # NEW: 封装组件调用，增加超时捕获
    async def _call_component(self, comp_name: str, inp: ComponentInput) -> ComponentOutput:
        comp = self.components[comp_name]
        try:
            # NEW: timeout 控制
            result = await asyncio.wait_for(
                comp.run(inp),
                timeout=comp.timeout
            )
            return result
        except asyncio.TimeoutError:
            return ComponentOutput(
                success=False,
                content=f"Component {comp_name} timeout",
                error_msg="timeout",
                need_more_info=False
            )
        except Exception as e:
            return ComponentOutput(
                success=False,
                content=f"Component {comp_name} error",
                error_msg=str(e),
                need_more_info=False
            )

    # NEW: ReAct 主循环：Thought → Action → Observation
    async def run_react_loop(self, user_query: str, max_rounds: int = 5):
        """
        ReAct 循环：
        每一轮：
        1. Thought 思考模块：输出 next_action
        2. 根据 next_action 调用对应 Action 组件
        3. 获取 Observation，写入 memory
        循环直到 next_action == finish 或达到最大轮次
        """
        print(f"\n===== Start ReAct, user query: {user_query} =====")
        self.memory.clear()
        self.chat_history.clear()

        for round_idx in range(max_rounds):
            print(f"\n--- ReAct Round {round_idx+1} ---")

            # Step1：调用 Thought 思考组件
            thought_input = ComponentInput(
                task_query=user_query,
                chat_history=self.chat_history,
                agent_memory=self.memory,
                module_name="thought"
            )
            thought_out = await self._call_component("thought", thought_input)
            if not thought_out.success:
                print(f"Thought failed: {thought_out.error_msg}")
                break
            print(thought_out.content)
            self.chat_history.append({"role":"assistant", "content": thought_out.content})

            next_action = thought_out.data.get("next_action", "finish")
            if next_action == "finish":
                print("ReAct loop finished, ready to answer user")
                break

            # Step2：调用 Action（工具/其他子模块）
            if next_action not in self.components:
                print(f"Action {next_action} not found")
                break

            action_input = ComponentInput(
                task_query=user_query,
                chat_history=self.chat_history,
                agent_memory=self.memory,
                module_name=next_action
            )
            action_out = await self._call_component(next_action, action_input)
            if not action_out.success:
                print(f"Action failed: {action_out.error_msg}")
                break
            print(action_out.content)

            # Step3：Observation 写入 memory，供下一轮思考读取
            self.memory["last_observation"] = action_out.data
            self.chat_history.append({"role":"assistant", "content": action_out.content})

        print("\n===== ReAct loop end =====")
        return self.memory

# ======================
# 运行入口
# ======================
async def main():
    agent = ReActAgentCore()
    await agent.run_react_loop(user_query="沈阳今天天气怎么样", max_rounds=5)

if __name__ == "__main__":
    asyncio.run(main())
改动位置梳理（对照代码）
异步改造
AgentComponent.run 改为 async def run
所有组件内部 LLM / IO 操作使用 await
主体调度函数 _call_component、run_react_loop 全部 async
入口使用 asyncio.run()
错误重试
新增 async_retry 装饰器，专门适配 async 函数
在组件 run 方法上加装饰器，可单独配置每个组件的 max_retries、delay

超时控制

_call_component 内部用 asyncio.wait_for 包裹组件调用
捕获 asyncio.TimeoutError，返回标准化失败 ComponentOutput

ReAct 循环
run_react_loop 是核心循环函数，限制最大轮次防止死循环
一轮完整流程：
Thought（思考，输出下一步动作）
Action（调用子组件 / 工具）
Observation（结果存入 memory，供下一轮思考读取）
循环终止条件：next_action == finish 或者到达最大轮数

                chat_history=self.chat_history,
                agent_memory=self.memory,
                module_name="thought"

            if not thought_out.success:
                print(f"Thought failed: {thought_out.error_msg}")
                break

            self.chat_history.append({"role":"assistant", "content": thought_out.content})

            next_action = thought_out.data.get("next_action", "finish")
            if next_action == "finish":
                print("ReAct loop finished, ready to answer user")
                break

            if next_action not in self.components:
                print(f"Action {next_action} not found")
                break

            action_input = ComponentInput(
                task_query=user_query,
                chat_history=self.chat_history,
                agent_memory=self.memory,
                module_name=next_action
            )
            action_out = await self._call_component(next_action, action_input)
            if not action_out.success:
                print(f"Action failed: {action_out.error_msg}")
                break
            print(action_out.content)

            self.memory["last_observation"] = action_out.data
            self.chat_history.append({"role":"assistant", "content": action_out.content})

        print("\n===== ReAct loop end =====")
        return self.memory

Human-in-the-loop 怎么做？
Human-in-the-loop（HITL）接入 ReAct Agent
核心思想：在 ReAct 循环里插入人工介入点。当满足某些条件时，Agent 暂停，把当前状态抛给人类；人类输入反馈后，Agent 恢复循环继续执行。
介入点选择（常用两处）
Thought 之后，Action 之前（推荐）：Agent 决定要调用某个工具 / 执行危险动作时，先问人确认。
Action 执行完，Observation 写入前：工具返回结果可疑，交给人校验、修正观察。
我们采用方案 1：Thought 产出 next_action 后，判断是否需要人工确认。
改动全部标注，基于上一份 agent_components.py。
改动思路
在 ComponentOutput 增加标记：need_human: bool，组件可以告诉主体：需要人工介入。
在 ReActAgentCore 的循环中：检测 need_human=True → 暂停，收集人类输入。
新增一个HumanInputComponent，专门负责接收人类反馈，把人类回答包装成标准化输出，放回 memory。
主体循环收到人类反馈后，继续下一轮 ReAct。
保留原有：异步、重试、超时、ReAct Thought/Action/Observation。

# ======================
# async 重试装饰器
# ======================
def async_retry(max_retries: int = 2, delay: float = 0.5):
    def decorator(func: Callable):
        @functools.wraps(func)
        async def wrapper(*args, **kwargs):
            attempt = 0
            while attempt <= max_retries:
                try:
                    return await func(*args, **kwargs)
                except Exception as e:
                    attempt += 1
                    if attempt > max_retries:
                        raise e
                    print(f"[Retry] attempt {attempt}, error: {str(e)}")
                    await asyncio.sleep(delay)
        return wrapper
    return decorator

# ======================
# ReAct Agent 主体【MODIFIED：增加HITL分支逻辑】
# ======================
class ReActAgentCore:
    def __init__(self):
        self.chat_history: List[Dict[str, str]] = []
        self.memory: Dict[str, Any] = {}
        # 注册组件，新增 human_input 和 delete_file_tool
        self.components: Dict[str, AgentComponent] = {
            "thought": ThoughtComponent(),
            "weather_tool": WeatherToolComponent(),
            "delete_file_tool": DeleteFileToolComponent(),
            "human_input": HumanInputComponent()
        }

    async def _call_component(self, comp_name: str, inp: ComponentInput) -> ComponentOutput:
        comp = self.components[comp_name]
        try:
            result = await asyncio.wait_for(
                comp.run(inp),
                timeout=comp.timeout
            )
            return result
        except asyncio.TimeoutError:
            return ComponentOutput(
                success=False,
                content=f"Component {comp_name} timeout",
                error_msg="timeout",
                need_more_info=False
            )
        except Exception as e:
            return ComponentOutput(
                success=False,
                content=f"Component {comp_name} error",
                error_msg=str(e),
                need_more_info=False
            )

    # NEW HITL：ReAct 主循环，增加人工介入分支
    async def run_react_loop(self, user_query: str, max_rounds: int = 5):
        print(f"\n===== Start ReAct, user query: {user_query} =====")
        self.memory.clear()
        self.chat_history.clear()

        for round_idx in range(max_rounds):
            print(f"\n--- ReAct Round {round_idx+1} ---")

            # Step1：调用 Thought
            thought_input = ComponentInput(
                task_query=user_query,
                chat_history=self.chat_history,
                agent_memory=self.memory,
                module_name="thought"
            )
            thought_out = await self._call_component("thought", thought_input)
            if not thought_out.success:
                print(f"Thought failed: {thought_out.error_msg}")
                break
            print(thought_out.content)
            self.chat_history.append({"role":"assistant", "content": thought_out.content})

            next_action = thought_out.data.get("next_action", "finish")

            # ======================
            # NEW HITL 核心分支
            # ======================
            if thought_out.need_human:
                print(f"Agent 准备执行高危动作：{next_action}，需要人工确认")
                human_input = ComponentInput(
                    task_query=user_query,
                    chat_history=self.chat_history,
                    agent_memory=self.memory,
                    module_name="human_input",
                    extra_params={
                        "human_prompt": f"即将执行动作【{next_action}】，是否继续？yes继续 / no取消"
                    }
                )
                human_out = await self._call_component("human_input", human_input)
                if not human_out.success:
                    print("人工交互失败，终止任务")
                    break
                print(human_out.content)
                self.chat_history.append({"role":"human", "content": human_out.content})
                # 保存人类回答到 memory
                self.memory["human_confirm"] = human_out.data["human_reply"]

                # 判断人类反馈
                if human_out.data["human_reply"].strip().lower() != "yes":
                    print("人类拒绝执行动作，任务终止")
                    break
                # human回答 yes：继续执行原本 next_action
            # ====================== END HITL ======================

            if next_action == "finish":
                print("ReAct loop finished, ready to answer user")
                break

            if next_action not in self.components:
                print(f"Action {next_action} not found")
                break

            # Step2：调用 Action
            action_input = ComponentInput(
                task_query=user_query,
                chat_history=self.chat_history,
                agent_memory=self.memory,
                module_name=next_action
            )
            action_out = await self._call_component(next_action, action_input)
            if not action_out.success:
                print(f"Action failed: {action_out.error_msg}")
                break
            print(action_out.content)

            # Step3：Observation写入memory
            self.memory["last_observation"] = action_out.data
            self.chat_history.append({"role":"assistant", "content": action_out.content})

        print("\n===== ReAct loop end =====")
        return self.memory

from typing import List, Optional, Dict, Any, Literal
from pydantic import BaseModel, Field, ConfigDict


# ======================
# Shared User State 共享用户状态（规范2）

class Profile(BaseModel):
    age: Optional[int] = None
    basic_profile: Optional[str] = None
    model_config = ConfigDict(extra="forbid")  # 禁止额外字段，防止随意扩展


class Pregnancy(BaseModel):
    gestational_week: Optional[float] = None
    estimated_due_date: Optional[str] = None
    model_config = ConfigDict(extra="forbid")

    report_type: Optional[str] = None
    report_date: Optional[str] = None
    extracted_data: Optional[Dict[str, Any]] = None
    source_file: Optional[str] = None
    model_config = ConfigDict(extra="forbid")


class Symptom(BaseModel):
    symptom: Optional[str] = None
    severity: Optional[str] = None
    timestamp: Optional[str] = None
    model_config = ConfigDict(extra="forbid")


class ConsultationRecord(BaseModel):
    query: Optional[str] = None
    response: Optional[str] = None
    evidence: Optional[List[str]] = Field(default_factory=list)
    timestamp: Optional[str] = None
    model_config = ConfigDict(extra="forbid")


class RiskStatus(BaseModel):
    level: Literal["LOW", "MODERATE", "HIGH", "UNKNOWN"] = "UNKNOWN"
    reasons: Optional[List[str]] = Field(default_factory=list)

    model_config = ConfigDict(extra="forbid")


class Consent(BaseModel):

    allow_external_escalation: Optional[bool] = None
    allow_family_notification: Optional[bool] = None

    profile: Optional[Profile] = None
    pregnancy: Optional[Pregnancy] = None
    medical_history: Optional[List[str]] = Field(default_factory=list)
    reports: Optional[List[Report]] = Field(default_factory=list)
    symptoms: Optional[List[Symptom]] = Field(default_factory=list)
    mood: Optional[str] = None
    appointments: Optional[List[Dict[str, Any]]] = Field(default_factory=list)
    consultation_history: Optional[List[ConsultationRecord]] = Field(default_factory=list)
    risk_status: Optional[RiskStatus] = None
    follow_up: Optional[Dict[str, Any]] = None
    consent: Optional[Consent] = None

    model_config = ConfigDict(extra="forbid")

# Audit Event 审计事件（规范6）

class AuditEvent(BaseModel):

    timestamp: str = Field(default_factory=lambda: datetime.utcnow().isoformat())
    request_id: str
    agent: str
    action: str
    data_accessed: List[str] = Field(default_factory=list)
    tool_used: Optional[str] = None
    source: List[str] = Field(default_factory=list)
    decision: str
    risk_level: Literal["LOW", "MODERATE", "HIGH", "UNKNOWN"] = "UNKNOWN"
    human_required: bool = False

    model_config = ConfigDict(extra="forbid")


# ======================
# Standard Agent Input（规范3）
# ======================
class AgentInput(BaseModel):

    user_id: str
    task: str

# Standard Agent Output（规范4、5）
# ======================
class AgentOutput(BaseModel):

    status: Literal["success", "needs_info", "escalate", "error"]
    summary: str
    evidence: List[str] = Field(default_factory=list)
    next_action: List[str] = Field(default_factory=list)
    risk_level: Literal["LOW", "MODERATE", "HIGH", "UNKNOWN"] = "UNKNOWN"
    requires_human: bool = False
    state_update: Dict[str, Any] = Field(default_factory=dict)
    audit_events: List[AuditEvent] = Field(default_factory=list)
    error: Optional[str] = None

    model_config = ConfigDict(extra="forbid")

关键规范落地说明
extra="forbid"：严格校验，不允许传入 / 返回不在定义内的字段，防止各 Agent 私自扩展 state
Literal 锁定枚举值：status、risk_level、requested_by，强制只能使用规范内允许的值，避免自定义如 critical/green
SharedUserState 完全对齐规范一级字段；嵌套子对象（Profile/Pregnancy 等）同样做强模型约束
AuditEvent 自动填充 UTC ISO 时间戳；保留 data_accessed 用于审计记录访问了哪些用户数据字段
state_update 是增量字典：Agent 不能直接修改 SharedUserState，只返回要更新的字段，由 orchestrator 合并写入全局状态（规范 1）

from reprojourney.schemas.base_schemas import AgentInput, AgentOutput, AuditEvent
import asyncio

AGENT_NAME = "thought_agent"

class ThoughtAgent:
    async def run(self, agent_input: AgentInput) -> AgentOutput:
        await asyncio.sleep(0.2)
        user_msg = agent_input.user_message or ""
        request_id = agent_input.request_id

        next_action: str
        requires_human: bool
        risk_level = "UNKNOWN"

        if "删除" in user_msg:
            thought_text = "识别到高危删除操作，需要人工确认后执行"
            next_action = "delete_tool_agent"
            requires_human = True
            risk_level = "HIGH"
        elif "天气" in user_msg:
            thought_text = "需要调用天气工具获取外部信息"
            next_action = "weather_tool_agent"
            requires_human = False
            risk_level = "LOW"
        else:
            thought_text = "信息充足，可以直接结束任务"
            next_action = "finish"
            requires_human = False

        audit_event = AuditEvent(
            request_id=request_id,
            agent=AGENT_NAME,
            action="react_thought",
            data_accessed=["user_message"],
            tool_used=None,
            source=[],
            decision=thought_text,
            risk_level=risk_level,
            human_required=requires_human
        )

        return AgentOutput(
            agent=AGENT_NAME,
            status="success",
            summary=thought_text,
            evidence=[],
            next_action=[next_action],
            risk_level=risk_level,
            requires_human=requires_human,
            state_update={},
            audit_events=[audit_event],
            error=None
        )

python
from copy import deepcopy
from typing import Dict, Optional, Tuple
from reprojourney.schemas.base_schemas import AgentInput, AgentOutput, SharedUserState, AuditEvent
from agents.thought_agent.thought_agent import ThoughtAgent
from agents.weather_tool_agent.weather_tool_agent import WeatherToolAgent
from agents.delete_tool_agent.delete_tool_agent import DeleteToolAgent

AGENT_NAME = "orchestrator"

# checkpoint 用于HITL暂停恢复
class OrchestratorCheckpoint:
    def __init__(self):
        self.request_id: str = ""
        self.user_id: str = ""
        self.state: SharedUserState
        self.context: Dict[str, Any]
        self.round: int = 0
        self.max_round: int = 5
        self.audit_events: list[AuditEvent] = []
        self.pending_next_agent: str = ""

class Orchestrator:
    def __init__(self):
        self.agent_map: Dict[str, Any] = {
            "thought_agent": ThoughtAgent(),
            "weather_tool_agent": WeatherToolAgent(),
            "delete_tool_agent": DeleteToolAgent()
        }
        self.checkpoints: Dict[str, OrchestratorCheckpoint] = {} # 内存存储，生产换Redis

    def _merge_state_update(self, base_state: SharedUserState, update: dict):
        """Orchestrator唯一允许修改SharedUserState的地方：增量合并state_update"""
        state_dict = base_state.model_dump()
        for k, v in update.items():
            if k in state_dict:
                # 如果是列表字段，append；直接覆盖简单字段
                if isinstance(state_dict[k], list) and isinstance(v, list):
                    state_dict[k].extend(v)
                else:
                    state_dict[k] = v
        return SharedUserState.model_validate(state_dict)

    async def start_react_flow(self, agent_input: AgentInput, max_rounds:int=5) -> Tuple[str, Optional[AgentOutput]]:
        """
        启动ReAct流程
        返回：flow_status, final_output
        flow_status: running | waiting_human | completed | error
        """
        request_id = agent_input.request_id
        cp = OrchestratorCheckpoint()
        cp.request_id = request_id
        cp.user_id = agent_input.user_id
        cp.state = deepcopy(agent_input.state)
        cp.context = deepcopy(agent_input.context)
        cp.round = 0
        cp.max_round = max_rounds
        cp.audit_events = []
        self.checkpoints[request_id] = cp

        return await self._run_react_loop(request_id)

    async def resume_after_human(self, request_id:str, human_confirm:bool) -> Tuple[str, Optional[AgentOutput]]:
        """HITL恢复入口：收到人工确认，继续ReAct循环"""
        if request_id not in self.checkpoints:
            return "error", None
        cp = self.checkpoints[request_id]
        cp.context["human_confirm"] = human_confirm
        return await self._run_react_loop(request_id)

    async def _run_react_loop(self, request_id:str) -> Tuple[str, Optional[AgentOutput]]:
        cp = self.checkpoints[request_id]
        while cp.round < cp.max_round:
            cp.round += 1
            # Step1：调用Thought Agent
            thought_input = AgentInput(
                request_id=cp.request_id,
                user_id=cp.user_id,
                task="react_thought",
                user_message=cp.context.get("original_user_msg"),
                state=cp.state,
                context=cp.context,
                requested_by="orchestrator"
            )
            thought_out: AgentOutput = await self.agent_map["thought_agent"].run(thought_input)
            cp.audit_events.extend(thought_out.audit_events)
            cp.state = self._merge_state_update(cp.state, thought_out.state_update)

            if thought_out.status == "error":
                return "error", thought_out

            next_action = thought_out.next_action[0] if thought_out.next_action else "finish"
            if thought_out.requires_human:
                cp.pending_next_agent = next_action
                return "waiting_human", AgentOutput(
                    agent=AGENT_NAME,
                    status="escalate",
                    summary=f"需要人工确认才能执行动作：{next_action}",
                    evidence=[],
                    next_action=[next_action],
                    risk_level="HIGH",
                    requires_human=True,
                    state_update={},
                    audit_events=cp.audit_events,
                    error=None
                )

            if next_action == "finish":
                return "completed", AgentOutput(
                    agent=AGENT_NAME,
                    status="success",
                    summary="ReAct任务完成",
                    evidence=[],
                    next_action=[],
                    risk_level="UNKNOWN",
                    requires_human=False,
                    state_update={},
                    audit_events=cp.audit_events,
                    error=None
                )

            # Step2：调用目标子Agent
            target_agent_name = next_action
            if target_agent_name not in self.agent_map:
                err_out = AgentOutput(
                    agent=AGENT_NAME,
                    status="error",
                    summary=f"找不到子Agent {target_agent_name}",
                    evidence=[],
                    next_action=[],
                    risk_level="UNKNOWN",
                    requires_human=False,
                    state_update={},
                    audit_events=cp.audit_events,
                    error="invalid next_action"
                )
                return "error", err_out

            action_input = AgentInput(
                request_id=cp.request_id,
                user_id=cp.user_id,
                task=f"call_{target_agent_name}",
                user_message=cp.context.get("original_user_msg"),
                state=cp.state,
                context=cp.context,
                requested_by="orchestrator"
            )
            action_out: AgentOutput = await self.agent_map[target_agent_name].run(action_input)
            cp.audit_events.extend(action_out.audit_events)
            cp.state = self._merge_state_update(cp.state, action_out.state_update)

            if action_out.status == "error":
                return "error", action_out

        # 超过最大轮次
        return "error", AgentOutput(
            agent=AGENT_NAME,
            status="error",
            summary="ReAct循环达到最大轮次限制",
            evidence=[],
            next_action=[],
            risk_level="UNKNOWN",
            requires_human=False,
            state_update={},
            audit_events=cp.audit_events,
            error="max round exceeded"
        )

python
from typing import List, Dict, Any
from reprojourney.schemas.base_schemas import SharedUserState

class MaternityRiskRuleEngine:
    """ReproJourney Maternity Risk Rule v1.0
    所有风险判定由结构化规则执行，LLM仅用于解释结论，禁止LLM自主定级
    """
    def __init__(self):
        self.risk_level = "UNKNOWN"
        self.reasons: List[str] = []
        self.requires_human = False

    def evaluate(self, state: SharedUserState) -> Dict[str, Any]:
        self.risk_level = "UNKNOWN"
        self.reasons = []
        self.requires_human = False

        # ========== 规则1：孕周评估 ==========
        preg = state.pregnancy
        if preg and preg.gestational_week is not None:
            gw = preg.gestational_week
            if gw > 42:
                self.risk_level = "HIGH"
                self.reasons.append("过期妊娠，孕周大于42周")
                self.requires_human = True
            elif gw < 37:
                # 早产孕周，再看症状
                has_preterm_symptom = False
                for sym in state.symptoms:
                    if sym.symptom in ["腹痛", "腹部坠胀", "规律宫缩"]:
                        has_preterm_symptom = True
                        break
                if has_preterm_symptom:
                    self.risk_level = "MODERATE"
                    self.reasons.append("孕周小于37周，伴随早产相关症状")
                else:
                    self.risk_level = "LOW"
                    self.reasons.append("孕周小于37周，无早产相关症状")

        # ========== 规则2：症状高危判断 ==========
        high_risk_symptoms = {"阴道出血", "破水", "规律性宫缩", "剧烈腹痛", "头晕晕厥", "视物模糊"}
        moderate_symptoms = {"轻微腰酸", "假性宫缩", "轻度水肿"}
        if state.symptoms:
            for sym in state.symptoms:
                s_name = sym.symptom
                if s_name in high_risk_symptoms:
                    self.risk_level = "HIGH"
                    self.reasons.append(f"存在高危症状：{s_name}")
                    self.requires_human = True
                elif s_name in moderate_symptoms and self.risk_level not in ["HIGH"]:
                    self.risk_level = "MODERATE"
                    self.reasons.append(f"存在需要随访的症状：{s_name}")

        # ========== 规则3：报告异常指标 ==========
        if state.reports:
            for rep in state.reports:
                ext_data = rep.extracted_data or {}
                abnormal_keys = ["bp_high", "glucose_high", "proteinuria", "fetal_heart_abnormal", "amniotic_fluid_abnormal"]
                for k in abnormal_keys:
                    if ext_data.get(k) is True:
                        self.risk_level = "HIGH"
                        self.reasons.append(f"报告{rep.report_id}存在异常指标：{k}")
                        self.requires_human = True

        # ========== 规则4：既往病史风险 ==========
        medical_history = state.medical_history or []
        high_risk_history = ["子痫前期", "瘢痕子宫", "既往早产史"]
        for item in medical_history:
            if item in high_risk_history:
                if self.risk_level != "HIGH":
                    self.risk_level = "MODERATE"
                    self.reasons.append(f"存在高危既往病史：{item}")

        # ========== 规则5：信息不足 ==========
        if len(self.reasons) == 0:
            self.risk_level = "UNKNOWN"
            self.reasons.append("没有足够用户信息完成风险评估")

        return {
            "risk_level": self.risk_level,
            "reasons": self.reasons,
            "requires_human": self.requires_human
        }

from reprojourney.schemas.base_schemas import AgentInput, AgentOutput, AuditEvent, RiskStatus
from reprojourney.schemas.risk_rules import MaternityRiskRuleEngine
import asyncio

AGENT_NAME = "risk_assessment_agent"

class RiskAssessmentAgent:
    async def run(self, agent_input: AgentInput) -> AgentOutput:
        await asyncio.sleep(0.2)
        request_id = agent_input.request_id
        user_state = agent_input.state

        # 执行结构化风险规则引擎
        rule_engine = MaternityRiskRuleEngine()
        result = rule_engine.evaluate(user_state)
        risk_level = result["risk_level"]
        reasons = result["reasons"]
        requires_human = result["requires_human"]

        # 构造审计事件
        audit_event = AuditEvent(
            request_id=request_id,
            agent=AGENT_NAME,
            action="run_maternity_risk_evaluation",
            data_accessed=["pregnancy", "symptoms", "reports", "medical_history"],
            tool_used="maternity_risk_rule_engine",
            source=["shared_user_state"],
            decision=f"风险评估结果：{risk_level}, reasons: {reasons}",
            risk_level=risk_level,
            human_required=requires_human
        )

        # 更新 state.risk_status，Orchestrator会合并
        state_update = {
            "risk_status": RiskStatus(
                level=risk_level,
                reasons=reasons,
                requires_human=requires_human

            status = "escalate"

            status = "needs_info"
        else:
            status = "success"

        return AgentOutput(
            agent=AGENT_NAME,
            status=status,
            summary=summary,
            evidence=reasons,
            next_action=[],
            risk_level=risk_level,
            requires_human=requires_human,

from reprojourney.schemas.base_schemas import AgentInput, AgentOutput, AuditEvent
import asyncio

AGENT_NAME = "governance_audit_agent"

class GovernanceAuditAgent:
    async def run(self, agent_input: AgentInput) -> AgentOutput:
        await asyncio.sleep(0.2)
        request_id = agent_input.request_id
        state = agent_input.state
        context = agent_input.context

        collected_audits: list[AuditEvent] = context.get("audit_events", [])
        consent = state.consent

        audit_check_errors: list[str] = []
        consent_check_errors: list[str] = []

        # 校验1：审计事件完整性检查
        for aud in collected_audits:
            if not aud.data_accessed:
                audit_check_errors.append(f"审计事件缺少 data_accessed, action:{aud.action}")

        # 校验2：Consent权限校验，如果需要升级但用户不允许外部升级
        risk_status = state.risk_status
        if risk_status and risk_status.level == "HIGH":
            if consent and consent.allow_external_escalation is False:
                consent_check_errors.append("当前为高风险，但用户未授权外部升级")

        all_errors = audit_check_errors + consent_check_errors
        risk_level = "LOW" if len(all_errors) == 0 else "MODERATE"

        decision_text = "治理审计校验通过，审计事件完整，用户授权合规"
        if all_errors:
            decision_text = "治理审计发现问题：" + "; ".join(all_errors)

        audit_event = AuditEvent(
            request_id=request_id,
            agent=AGENT_NAME,
            action="governance_audit_validation",
            data_accessed=["consent", "risk_status"],
            tool_used=None,
            source=["audit_events_collection"],
            decision=decision_text,
            risk_level=risk_level,
            human_required=False
        )

        summary = decision_text
        status = "success" if len(all_errors) == 0 else "needs_info"

        return AgentOutput(
            agent=AGENT_NAME,
            status=status,
            summary=summary,
            evidence=all_errors,
            next_action=[],
            risk_level=risk_level,
            requires_human=False,
            state_update={},
            audit_events=[audit_event],
            error=None
        )

from copy import deepcopy
from typing import Dict, Optional, Tuple, Literal
from reprojourney.schemas.base_schemas import AgentInput, AgentOutput, SharedUserState, AuditEvent
from agents.thought_agent.thought_agent import ThoughtAgent
from agents.weather_tool_agent.weather_tool_agent import WeatherToolAgent
from agents.delete_tool_agent.delete_tool_agent import DeleteToolAgent
from agents.risk_agent.agent4_risk_assessment import RiskAssessmentAgent
from agents.governance_audit.agent5_governance_audit import GovernanceAuditAgent

AGENT_NAME = "orchestrator"

class OrchestratorCheckpoint:
    def __init__(self):
        self.request_id: str = ""
        self.user_id: str = ""
        self.state: SharedUserState
        self.context: Dict[str, Any]
        self.round: int = 0
        self.max_round: int = 5
        self.audit_events: list[AuditEvent] = []
        self.pending_next_agent: str = ""
        # HITL人工复核缓存
        self.pending_risk_result: Optional[Dict] = None

class Orchestrator:
    def __init__(self):
        self.agent_map: Dict[str, Any] = {
            "thought_agent": ThoughtAgent(),
            "weather_tool_agent": WeatherToolAgent(),
            "delete_tool_agent": DeleteToolAgent(),
            "risk_assessment_agent": RiskAssessmentAgent(),
            "governance_audit_agent": GovernanceAuditAgent()
        }
        self.checkpoints: Dict[str, OrchestratorCheckpoint] = {}

    def _merge_state_update(self, base_state: SharedUserState, update: dict):
        state_dict = base_state.model_dump()
        for k, v in update.items():
            if k in state_dict:
                if isinstance(state_dict[k], list) and isinstance(v, list):
                    state_dict[k].extend(v)
                else:
                    state_dict[k] = v
        return SharedUserState.model_validate(state_dict)

    async def start_react_flow(self, agent_input: AgentInput, max_rounds:int=5) -> Tuple[str, Optional[AgentOutput]]:
        request_id = agent_input.request_id
        cp = OrchestratorCheckpoint()
        cp.request_id = request_id
        cp.user_id = agent_input.user_id
        cp.state = deepcopy(agent_input.state)
        cp.context = deepcopy(agent_input.context)
        cp.round = 0
        cp.max_round = max_rounds
        cp.audit_events = []
        self.checkpoints[request_id] = cp
        return await self._run_react_flow(request_id)

    async def resume_after_human(
        self,
        request_id:str,
        human_action: Literal["approve", "override", "reject"],
        human_reviewer: str,
        revised_risk_level: Optional[Literal["LOW", "MODERATE", "HIGH", "UNKNOWN"]] = None,
        human_decision_note: str = ""
    ) -> Tuple[str, Optional[AgentOutput]]:
        """
        HITL恢复入口：孕产风险人工复核
        human_action: approve / override / reject
        """
        if request_id not in self.checkpoints:
            return "error", None
        cp = self.checkpoints[request_id]

        # 生成人工复核审计事件
        old_risk = cp.pending_risk_result.get("risk_level", "UNKNOWN") if cp.pending_risk_result else "UNKNOWN"
        final_risk = revised_risk_level if human_action == "override" else old_risk

        human_audit = AuditEvent(
            request_id=request_id,
            agent=AGENT_NAME,
            action="human_risk_review",
            data_accessed=["risk_status"],
            tool_used=None,
            source=["risk_assessment_agent"],
            decision=f"Reviewer:{human_reviewer}, action:{human_action}, old_risk:{old_risk}, new_risk:{final_risk}, note:{human_decision_note}",
            risk_level=final_risk,
            human_required=False
        )
        cp.audit_events.append(human_audit)

        # 更新context，把人工复核结果传给后续Governance Agent
        cp.context["human_review"] = {
            "reviewer": human_reviewer,
            "action": human_action,
            "revised_risk_level": final_risk,
            "note": human_decision_note
        }
        return await self._run_react_flow(request_id)

    async def _run_react_flow(self, request_id:str) -> Tuple[str, Optional[AgentOutput]]:
        cp = self.checkpoints[request_id]
        while cp.round < cp.max_round:
            cp.round += 1
            # Step1：Thought Agent
            thought_input = AgentInput(
                request_id=cp.request_id,
                user_id=cp.user_id,
                task="react_thought",
                user_message=cp.context.get("original_user_msg"),
                state=cp.state,
                context=cp.context,
                requested_by="orchestrator"
            )
            thought_out: AgentOutput = await self.agent_map["thought_agent"].run(thought_input)
            cp.audit_events.extend(thought_out.audit_events)
            cp.state = self._merge_state_update(cp.state, thought_out.state_update)

            if thought_out.status == "error":
                return "error", thought_out

            next_action = thought_out.next_action[0] if thought_out.next_action else "finish"
            if next_action == "risk_assessment_agent":
                # Step2：调用Risk Assessment Agent
                risk_input = AgentInput(
                    request_id=cp.request_id,
                    user_id=cp.user_id,
                    task="run_risk_assessment",
                    user_message=cp.context.get("original_user_msg"),
                    state=cp.state,
                    context=cp.context,
                    requested_by="orchestrator"
                )
                risk_out: AgentOutput = await self.agent_map["risk_assessment_agent"].run(risk_input)
                cp.audit_events.extend(risk_out.audit_events)
                cp.state = self._merge_state_update(cp.state, risk_out.state_update)
                cp.pending_risk_result = {
                    "risk_level": risk_out.risk_level,
                    "requires_human": risk_out.requires_human
                }

                # HIGH风险触发HITL暂停
                if risk_out.requires_human:
                    cp.pending_next_agent = "governance_audit_agent"
                    return "waiting_human", AgentOutput(
                        agent=AGENT_NAME,
                        status="escalate",
                        summary=f"风险评估为{HIGH}，等待人工医疗复核",
                        evidence=risk_out.evidence,
                        next_action=["governance_audit_agent"],
                        risk_level=risk_out.risk_level,
                        requires_human=True,
                        state_update={},
                        audit_events=cp.audit_events,
                        error=None
                    )
                # 无需人工复核，直接流转Governance
                next_action = "governance_audit_agent"

            if next_action == "governance_audit_agent":
                gov_input = AgentInput(
                    request_id=cp.request_id,
                    user_id=cp.user_id,
                    task="run_governance_audit",
                    user_message=cp.context.get("original_user_msg"),
                    state=cp.state,
                    context={**cp.context, "audit_events": cp.audit_events},
                    requested_by="orchestrator"
                )
                gov_out: AgentOutput = await self.agent_map["governance_audit_agent"].run(gov_input)
                cp.audit_events.extend(gov_out.audit_events)
                cp.state = self._merge_state_update(cp.state, gov_out.state_update)
                next_action = "finish"

            if next_action == "finish":
                return "completed", AgentOutput(
                    agent=AGENT_NAME,
                    status="success",
                    summary="孕产风险评估与治理审计流程全部完成",
                    evidence=[],
                    next_action=[],
                    risk_level=cp.pending_risk_result.get("risk_level", "UNKNOWN") if cp.pending_risk_result else "UNKNOWN",
                    requires_human=False,
                    state_update={},
                    audit_events=cp.audit_events,
                    error=None
                )

            # 通用子Agent调用分支（原有示例agent）
            target_agent_name = next_action
            if target_agent_name not in self.agent_map:
                err_out = AgentOutput(
                    agent=AGENT_NAME,
                    status="error",
                    summary=f"找不到子Agent {target_agent_name}",
                    evidence=[],
                    next_action=[],
                    risk_level="UNKNOWN",
                    requires_human=False,
                    state_update={},
                    audit_events=cp.audit_events,
                    error="invalid next_action"
                )
                return "error", err_out

            action_input = AgentInput(
                request_id=cp.request_id,
                user_id=cp.user_id,
                task=f"call_{target_agent_name}",
                user_message=cp.context.get("original_user_msg"),
                state=cp.state,
                context=cp.context,
                requested_by="orchestrator"
            )
            action_out: AgentOutput = await self.agent_map[target_agent_name].run(action_input)
            cp.audit_events.extend(action_out.audit_events)
            cp.state = self._merge_state_update(cp.state, action_out.state_update)

            if action_out.status == "error":
                return "error", action_out

        return "error", AgentOutput(
            agent=AGENT_NAME,
            status="error",
            summary="ReAct循环达到最大轮次限制",
            evidence=[],
            next_action=[],
            risk_level="UNKNOWN",
            requires_human=False,
            state_update={},
            audit_events=cp.audit_events,
            error="max round exceeded"
        )

# 评测集：真值标签
EVAL_DATASET = [
    {
        "case_id": "case_001",
        "description": "过期妊娠+阴道出血 → HIGH，触发HITL",
        "ground_truth_risk": "HIGH",
        "ground_truth_requires_human": True,
        "state": SharedUserState(
            user_id="eval_001",
            profile=Profile(age=32),
            pregnancy=Pregnancy(gestational_week=42.3),
            symptoms=[Symptom(symptom="阴道出血", severity="high")],
            consent=Consent(allow_record_storage=True, allow_external_escalation=True)
        )

    {
        "case_id": "case_002",
        "description": "孕30周，无异常症状 → LOW",
        "ground_truth_risk": "LOW",
        "ground_truth_requires_human": False,
        "state": SharedUserState(
            user_id="eval_002",
            profile=Profile(age=28),
            pregnancy=Pregnancy(gestational_week=30),
            symptoms=[],
            consent=Consent(allow_record_storage=True, allow_external_escalation=True)
        )
    },
    {
        "case_id": "case_003",
        "description": "信息不足 → UNKNOWN",
        "ground_truth_risk": "UNKNOWN",
        "ground_truth_requires_human": False,
        "state": SharedUserState(user_id="eval_003", profile=None)
    }
]

async def run_eval():
    orchestrator = Orchestrator()
    result_records: List[Dict] = []
    hit = 0
    miss = 0
    false_positive = 0

    for case in EVAL_DATASET:
        req_id = str(uuid4())
        inp = AgentInput(
            request_id=req_id,
            user_id=case["state"].user_id,
            task="user_query",
            user_message="评估孕产风险",
            state=case["state"],
            context={"original_user_msg":"评估孕产风险"},
            requested_by="user"
        )
        flow_status, out = await orchestrator.start_react_flow(inp)
        pred_risk = out.risk_level
        pred_human = out.requires_human
        gt_risk = case["ground_truth_risk"]
        gt_human = case["ground_truth_requires_human"]

        record = {
            "case_id": case["case_id"],
            "description": case["description"],
            "gt_risk": gt_risk,
            "pred_risk": pred_risk,
            "gt_human": gt_human,
            "pred_human": pred_human,
            "pass": pred_risk == gt_risk and pred_human == gt_human
        }
        result_records.append(record)
        if record["pass"]:
            hit += 1
        else:
            if gt_risk == "HIGH" and pred_risk != "HIGH":
                miss +=1
            if gt_risk != "HIGH" and pred_risk == "HIGH":
                false_positive +=1

    total = len(EVAL_DATASET)
    accuracy = hit / total if total>0 else 0
    report = f"""
# Risk Agent Evaluation Report
Total cases: {total}
Passed: {hit}
Accuracy: {accuracy:.2%}
Miss rate (HIGH not detected): {miss/total if total>0 else 0:.2%}
False positive rate (wrong HIGH): {false_positive/total if total>0 else 0:.2%}
"""
    print(report)
    for r in result_records:
        print(r)
    return report, result_records

if __name__ == "__main__":
    asyncio.run(run_eval())
